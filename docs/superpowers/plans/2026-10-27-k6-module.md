# k6 Performance Testing Module Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the flat module `/k6/` with 19 topic pages in 5 parts, based on the owner's notes "Learn K6" and the official k6 docs.

**Architecture:** Task 1 adds the module data, routes, registry line, strings, images, tests, and 19 skeleton MDX pages, so all counts change one time. Tasks 2–6 replace the skeletons with real pages, one part for each task. Task 7 runs the release checks and updates the docs.

**Tech Stack:** Next.js 16 static export, MDX, `node --test`, Python 3 check scripts, Pillow (for the WebP images).

**Spec:** `docs/superpowers/specs/2026-10-27-k6-module-design.md`
