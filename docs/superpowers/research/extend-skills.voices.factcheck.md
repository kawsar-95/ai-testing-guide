# Voice fact-check: Skills & Commands (round 1, 2026-10-20)

Page: `content/extend/skills.mdx`. I did not write this page.

Method: I read the 7 `<Voices>` blocks. For each claim in a `<Layman>` or `<Bangla>` panel, I found the `<Technical>` sentence of the same `##` section that it restates. A claim that is not in the Technical panel, or that changes a number, a version, a flag, a command, a path, a scope, or a condition, is a FAIL. An omission is not a FAIL. For each `<Cite n>` in a voice panel, I checked that the Technical panel of the same section cites the same `n` for the same claim. I read the Bangla text for meaning and for natural use. I checked that common technical terms stay in English and that an English word and a Bangla suffix have a hyphen. The `## Reference` Technical tables are the source for the field and placeholder claims. I did not edit the page.

Notes from the check:
