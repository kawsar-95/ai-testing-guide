## Removed

- "Diffusion models start from noise and remove it step by step": the DDPM abstract does not say this in these words. The page uses the abstract's "progressive" description (C16).
- "Gemini can edit images": not checked in the fetched part of S2. The tools table says only that it makes images.

- The EU AI Act Article 50 duty to mark synthetic content: the eur-lex page did not load in this session, so the page gives disclosure as the tutorial's own advice and links to the AI Governance page.
- A claim that OpenAI images carry C2PA metadata: the help article returned HTTP 403, and the fetched API guide does not say it. The page cites SynthID (Gemini) for a vendor that marks its images.
