Method: I read the 5 `<Voices>` blocks. For each claim in a `<Layman>` or `<Bangla>` panel, I found the `<Technical>` sentence of the same `##` section that it restates. A claim that is not in the Technical panel, or that changes a number, a condition, a scope, or a product name, is a FAIL. An omission is not a FAIL. For each `<Cite n>` in a voice panel, I checked that the Technical panel of the same section cites the same `n` and that the cite follows the same claim there. I read the Bangla text for meaning and for natural use (আপনি, English technical terms, a hyphen between an English word and a Bangla suffix). A language problem is a FAIL only if it changes or hides the meaning. The "Key words" section has no voices.
