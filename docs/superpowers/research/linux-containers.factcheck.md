Sources fetched by the checker on 2026-10-19 with `scripts/linux_fetch.py` into `<scratch dir>` (53 files, all status `ok`): the 44 pages of `page.sources` 2 to 45 (file NNN = page source number minus 1, for example S5 Wiz = 004, S12 kernel cgroup v2 = 011, S24 `docker container run` = 023), and 9 extra pages (`docs.docker.com/engine/storage/containerd/`, containerd README, `docker run` guide, `proc_pid_cgroup(5)`, `user_namespaces(7)`, run metrics, `containerd.io/docs/`, `docker container kill`, engine install). Docker was NOT used. Safety rule kept: I ran no `docker run/pull/build/exec/rm/rmi/stop/kill/system prune/compose`, no `podman`, `runc`, `ctr`, `unshare`, `mount`; no registry contact; no sudo; nothing written under `/sys/fs/cgroup`. No real container name, host name, user name, or ID of the machine is in this report.

Verdicts: PASS = the source supports it (quote 25 words or fewer). FAIL = wrong, unsupported, or a quality problem, with the fix. OPINION-OK = advice or framing. EXAMPLE-OK = a read-only command that I ran, or a Docker command that the official page documents (not run).
