Verdicts: PASS = the source supports it (quote 25 words or fewer). FAIL = wrong, unsupported, or a quality problem, with the fix. OPINION-OK = advice or framing. EXAMPLE-OK = a read-only command that I ran, or a Docker command that the official page documents (not run).
