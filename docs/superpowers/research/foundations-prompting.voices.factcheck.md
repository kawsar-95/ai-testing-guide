- Layman and Bangla, "Give Claude a way to verify its work": "To make the check end the task" and "Check-কে task-এর শেষ ধাপ বানাতে" are looser than "make the check gate the end of the task" (the Stop hook blocks the end until the check passes). The meaning is close, so it is not a FAIL. Better: "To make the task end only when the check passes" and "Task তখনই শেষ হবে, যখন check pass করবে - এটি নিশ্চিত করতে".
- Bangla, "Examples for QA tasks": "আগের test file" is better written "বিদ্যমান test file" (existing test files).
- Bangla, "Point Claude at your material": "এছাড়া" is better written "এ ছাড়া". It does not change the meaning.
- The Bangla keeps the common technical terms in English (check, test, build, scope, symptom, edge case, prompt, plan mode, status bar, subagent, hook, context, session, spec, token, directory, CLI tool). Hyphens join an English word and a Bangla suffix ("Claude-কে", "task-এর", "file-এর"). The text uses "আপনি" forms. The commands, flags, and paths stay in backticks. I found no other language problem.
