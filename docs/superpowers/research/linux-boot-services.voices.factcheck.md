Method: I read the 8 `<Voices>` blocks. For each claim in a `<Layman>` or `<Bangla>` panel, I found the `<Technical>` sentence of the same `##` section that it restates. The page intro and the code blocks have no voices. The `Why it matters for testing` and danger callouts are part of the Technical panel, so I used them as the source for the Layman and Bangla cautions and tips.
