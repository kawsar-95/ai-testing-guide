# Voice fact-check: How Slack Works (system-design/slack, round 1, 2026-10-20)

Page: `content/system-design/slack.mdx`. I did not write this page.

Method: I read the 9 `<Voices>` blocks (the "Key words" section has no voices). For each claim in a `<Layman>` or `<Bangla>` panel, I found the `<Technical>` sentence of the same `##` section that it restates. A claim that is not in the Technical panel, or that changes a number, a version, a name, a scope, or a condition, is a FAIL. An omission is not a FAIL. For each `<Cite n>` in a voice panel, I checked that the Technical panel of the same section cites the same `n` and that the cite follows the same claim (a cite at the end of a paragraph, where Technical cites each sentence, is a PASS because the source is the same). I did not re-check the facts against the sources; `system-design-slack.factcheck.md` does that. I read the Bangla text for meaning and for natural use (polite আপনি, technical terms in English, hyphen between an English word and a Bangla suffix).
