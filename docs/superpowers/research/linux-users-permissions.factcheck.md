## Weak points flagged by the writer
- **RHEL facts from the Red Hat blog (S20).** The blog (Seth Kenlon, 30 June 2022, redhat.com) says "Lock root at installation" and "Making the user an admin adds that user to the special wheel group". It is a vendor source and it supports the two statements, so the rows pass. `docs.redhat.com` could not be fetched (robots), so I could not compare with the RHEL manual. Suggestion, not a FAIL: write "A Red Hat blog advises" instead of "Red Hat advises", because one blog post is not the product policy.
- **"chown needs root" is not claimed.** Confirmed: no such sentence on the page.
- **Debian vs RHEL.** `adduser` is a Debian tool (row PASS). Home directory default: the Fedora default has only a blog source (FAIL). `USERGROUPS_ENAB` is not on the page. The package name `shadow-utils` is RHEL only (FAIL).
- **`usermod -aG` vs `-G`:** correct on the page and in the danger callout. The roadmap source S17 writes `usermod -G -a`, which is wrong; the page does not copy it.
- **sudoers statements:** `/etc/sudoers.d`, `visudo`, `NOPASSWD`, last match, skip rules all pass. The 5-minute default fails for sudo-rs (Ubuntu 25.10 and later).
- **Octal tables, umask, chmod examples:** computed and run in the sandbox; all agree with the page. Only the `ls -l` comment of the first File Permissions block depends on the umask (FAIL).
- **Danger callouts:** present after each of the 3 blocks that change accounts, sudoers, or modes. **Tips:** no unsafe advice (no `chmod 777`, no password in a script).
