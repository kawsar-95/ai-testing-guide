# Voice fact-check: Linux Troubleshooting (round 1, 2026-10-20)

Page: `content/linux/troubleshooting.mdx`. I did not write this page.

Method: I read the 6 `<Voices>` blocks (Server Review, Uptime and Load, Available Memory and Disk, System Logs, Authentication Logs, Troubleshooting). For each claim in a `<Layman>` or `<Bangla>` panel, I found the `<Technical>` sentence of the same `##` section that it restates. A claim that is not in the Technical panel, or that changes a number, a version, a flag, a command, a path, a product name, a scope, or a condition, is a FAIL. An omission is not a FAIL. For each `<Cite n>` in a voice panel, I checked that the Technical panel of the same section cites the same `n`, and that the cite sits after the same claim as in the Technical panel. I did not re-check the sources. The Technical text is the base, and the page's own fact-check owns it. I read the Bangla text for meaning, for the polite form (আপনি), for common technical terms in English, and for the hyphen between an English word and a Bangla suffix. A language problem is a FAIL only if it changes or hides the meaning. The intro paragraph under the `#` heading has no voices.

Flagged items:

- "it can be lower than `nproc --all`" (Uptime and Load, Bangla): the Bangla word এটি ("it") can be read as "the load" and not as `nproc`. The Technical sentence has the same "it", but the English "it" is next to `nproc`. The cite and the claim are the same. PASS, with a language note (Uptime and Load, Bangla, cgroup row).
- "You can also read the journal" (Authentication Logs, Layman): the Technical sentence says "Else read the journal", which depends on the `SyslogFacility` check. The Layman text is a weaker, unconditional offer. It adds no fact, because reading the journal is allowed in both texts. PASS, with a note (Authentication Logs, Layman, journal row).
- Bangla "Available Memory and Disk" last paragraph: the CI advice (run `df -h`, `df -i`, `free -h` at the start and the end of a CI job) comes from the Technical tip callout. It sits in the paragraph that starts with "Tutorial-এর নিজের পরামর্শ", so it is marked as the tutorial's own advice. PASS (Available Memory and Disk, Bangla, CI row).
- Omissions that I did not count as FAIL: the Layman text drops the vmstat `si`/`so` sentence, the `Storage=` sentence, the `CAP_SYSLOG` sentence, the `faillog` sentence, and the `drop_caches` cost and "do not tune" advice. The Bangla text drops the `Storage=` caveat of Layman, the `CAP_SYSLOG` sentence, and the PSI `avg`/`total` fields.
