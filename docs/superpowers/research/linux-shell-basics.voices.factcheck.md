# Voice fact-check: Shell Basics (round 1 and recheck 1, 2026-10-20)

Page: `content/linux/shell-basics.mdx`. I did not write this page.

Method: I read the 7 `<Voices>` blocks. For each claim in a `<Layman>` or `<Bangla>` panel, I found the `<Technical>` sentence of the same `##` section that it restates. A claim that is not in the Technical panel, or that changes a number, a condition, a command, a flag, a path, or a scope, is a FAIL. An omission is not a FAIL. For each `<Cite n>` in a voice panel, I checked that the Technical panel of the same section cites the same `n` and that the cite follows the same claim. I read the Bangla text for meaning and for natural use (polite আপনি, technical terms in English, a hyphen between an English word and a Bangla suffix). A language problem is a FAIL only if it hides the meaning. I did not re-check the Technical claims against the sources; that is the job of the page fact-check report.

Findings:

- Round 1: rows 3, 12, and 25 (all in Shell Basics) were FAILs. They are fixed (see Recheck 1).
- Advice paragraphs in the other sections lose the label "Tutorial's own advice" in the voice panels. They have no cite, so they do not look like sourced facts. PASS.
- Bangla: the round 1 language notes ("মানে", "logical ভাবে", "পুরোনো legacy", "আগের কোনো directory") are fixed. One small note remains in row 25.
