# Voice fact-check: Subagents (round 1, 2026-10-20)

Page: `content/extend/subagents.mdx`. I did not write this page.

Method: I read the 7 `<Voices>` blocks. For each claim in a `<Layman>` or `<Bangla>` panel, I found the `<Technical>` sentence of the same `##` section that it restates (the code blocks, tables, and callouts of the Technical panel count as Technical text). A claim that is not in the Technical panel, or that changes a number, a version, a condition, or a scope, is a FAIL. An omission is not a FAIL. For each `<Cite n>` in a voice panel, I checked that the Technical panel of the same section cites the same `n` for the same claim. I read the Bangla text for meaning and for natural use (polite আপনি, technical terms in English, a hyphen between an English word and a Bangla suffix). A language problem is a FAIL only if it changes or hides the meaning.

Findings:

- Recheck 1 (see the note at the end): the one FAIL of round 1 (row 93) is fixed. No open FAIL remains.
