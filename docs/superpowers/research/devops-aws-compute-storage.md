Page: `content/devops/aws-compute-storage.mdx`. Module: DevOps & Cloud. Date: 2026-11-18 (first version: 2026-11-05).

The first version (2026-11-05) had three sources and one section. The page needs no AWS account: nothing on it runs against AWS. The tutorial does not give a price anywhere, because prices change; it cites the AWS pages that say what is billed.

The practice run of `## Try it` (steps 1 to 4) was run on 2026-11-18 at 12:13:48 (+06) on Linux 7.0.0-43-generic with bash 5.3.9 and aws-cli/2.41.0 (Python 3.14.8).
