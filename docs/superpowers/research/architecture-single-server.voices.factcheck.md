# Voice fact-check: Single Server (round 1, 2026-10-20)

Method: I read the 5 `<Voices>` blocks. For each claim in a `<Layman>` or `<Bangla>` panel, I found the `<Technical>` sentence of the same `##` section that it restates. A claim that is not in the Technical panel, or that changes a number, a product name, a scope, or a condition, is a FAIL. An omission is not a FAIL. For each `<Cite n>` in a voice panel, I checked that the Technical panel of the same section cites the same `n` after the same claim. I also checked that `architecture-single-server.factcheck.md` (round 1, `Open FAILs: 0`) has a PASS quote for that claim. I read the Bangla text for meaning and for natural use: the polite form (আপনি), technical terms in English, and a hyphen between an English word and a Bangla suffix. A language problem is a FAIL only if it changes or hides the meaning. The lede and the "Key words" section have no voices.
