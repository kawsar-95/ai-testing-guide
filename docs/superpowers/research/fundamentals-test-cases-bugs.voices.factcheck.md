# Voice fact-check: Test Cases, Bugs and Completion (round 1, 2026-10-20; recheck 1)

Page: `content/fundamentals/test-cases-bugs.mdx`. I did not write the voices of this page.

Method: I read the 7 `<Voices>` blocks. For each claim in a `<Layman>` or `<Bangla>` panel, I found the `<Technical>` sentence of the same `##` section and of the same version block (notes or istqb) that it restates. A claim that is not in that Technical block, or that changes a number, a term, a list, a step order, a scope, or a condition, is a FAIL. An omission is not a FAIL. I checked that each voice panel has exactly one `notes` block and one `istqb` block, that no `notes` block has a `<Cite>`, and that each `<Cite n>` in an `istqb` block uses an n that the same Technical `istqb` block cites for the same claim. I checked that no panel mixes the notes text and the istqb text. I read the Bangla text for meaning, for polite form (আপনি), and for English technical terms. The research report `fundamentals-test-cases-bugs.factcheck.md` already checks the Technical text against the sources, so I did not check the sources again.
