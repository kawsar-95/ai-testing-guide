Local checks (sandbox `<scratch dir>/factcheck-shell-scripting/sandbox`, bash 5.3.9, dash 0.5.12-12ubuntu3, no root, no system change): the six `bash` blocks were extracted and run with `bash` in empty directories. Use globs.", SC2164 is "Use `cd ... || exit` in case `cd` fails."
