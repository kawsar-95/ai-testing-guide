# Voice fact-check: Cloud Architecture (round 1, 2026-10-20)

Method: I read the 5 `<Voices>` blocks. For each claim in a `<Layman>` or `<Bangla>` panel, I found the `<Technical>` sentence of the same `##` section that it restates. A claim that is not in the Technical panel, or that changes a number, a condition, a product name, or a scope, is a FAIL. An omission is not a FAIL. For each `<Cite n>` in a voice panel, I checked that the same `n` is cited in the Technical panel of the same section, and that it follows the same claim there. The sources are the same as in the Technical panel, so I did not fetch them again. I read the Bangla text for meaning and for natural use, and I checked that common technical terms stay in English, that the address is polite (আপনি), and that an English word and a Bangla suffix have a hyphen. The "Key words" section has no voices.

Notes on items that look new but are not:

- "What a tester can check": the Layman and Bangla panels start with "the tutorial's own advice" and repeat the 5 ideas with no cites. The Technical panel has no cites there. PASS, rows 70 to 81.
- The Callout box of the Technical panel is not repeated in the voices. The text inside it is repeated. PASS.
