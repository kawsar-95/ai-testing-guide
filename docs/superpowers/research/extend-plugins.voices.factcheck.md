# Voice fact-check: Plugins and Marketplaces (round 1, recheck 1, 2026-10-20)

Page: `content/extend/plugins.mdx`. I did not write this page.

Method: I read the 7 `<Voices>` blocks. For each claim in a `<Layman>` or `<Bangla>` panel, I found the `<Technical>` sentence of the same `##` section that it restates. A claim that is not in the Technical panel, or that changes a number, a version, a flag, a command, a path, a product name, a scope, or a condition, is a FAIL. An omission is not a FAIL. For each `<Cite n>` in a voice panel, I checked that the Technical panel of the same section cites the same n for the same claim. I read the Bangla text for meaning and for natural use (polite "আপনি" form, technical terms in English, a hyphen between an English word and a Bangla suffix). A language problem is a FAIL only if it changes or hides the meaning. I did not check the Technical panels against the sources. This report checks only that the voices agree with the Technical panels. Recheck 1: I read all 7 blocks again against the current file. I compared the `<Cite n>` set of each voice panel with the Technical panel by script: no voice panel cites an n that its Technical panel does not cite.

Results: 142 rows, 0 FAILs. The first check found 2 FAILs (rows 58 and 124, both Layman). Both are fixed. See "Recheck 1".

Flagged items (round 1, all still true after the recheck):

- Layman "Install and manage": "It is off for all other marketplaces." drops "by default" (row 58).
- Layman "Build a team marketplace": "A team marketplace is a file" changes "A marketplace file lives at" (row 124).
- Layman "Marketplaces": "cannot look like an Anthropic one" is looser than "cannot present itself as an Anthropic one". The reason (the reserved names) is the same. PASS.
- Layman and Bangla "Example: the Superpowers plugin": "a couple of hours" and "কয়েক ঘণ্টা" are close. PASS with a language note.
- The Bangla panels leave out the `#ref` pin, the `--json` and `--strict` flags, and the Technical code blocks. An omission is not a FAIL.
