Method: I read the 8 `<Voices>` blocks. For each claim in a `<Layman>` or `<Bangla>` panel, I found the `<Technical>` sentence of the same `##` section that it restates. A claim that is not in the Technical panel, or that changes a number, version, flag, command, path, product name, scope, or condition, is a FAIL. An omission is not a FAIL. For each `<Cite n>` in a voice panel, I checked that the same `n` is cited by the Technical panel of the same section and that it follows the same claim. I read the Bangla text for meaning and natural use: polite form (আপনি), technical terms in English, hyphen between an English word and a Bangla suffix. A language problem is a FAIL only if it changes or hides the meaning. I did not re-check the Technical text against the sources. The Technical text is the base, and the page's own fact-check covers it.
