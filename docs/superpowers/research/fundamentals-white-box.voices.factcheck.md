Method: I read the 7 `<Voices>` blocks. This chapter has two versions of each topic, so I checked each voice `<Version>` block against the matching `<Technical>` block of the same `##` section: `notes` against `notes`, and `istqb` against `istqb`. For each claim in a `<Layman>` or `<Bangla>` panel, I found the `<Technical>` sentence that it restates. A claim that is not in the Technical block, or that changes a number, a term, a list, a step order, a scope, or a condition, is a FAIL. An omission is not a FAIL. I also checked the structure with a script: each panel has exactly one `notes` and one `istqb` block (7 of 7 sections, 3 of 3 panels), no `<Cite>` is in a `notes` block, and each voice `istqb` block cites only `n` values that the Technical `istqb` block of the same section cites. For each cite, I checked that the source in `page.sources` is the one that the Technical sentence uses for the same claim. I read the Bangla text for meaning and for natural use, and I checked that testing terms stay in English and that a hyphen joins an English word and a Bangla suffix. The Bangla text uses the polite form (`আপনার`, `করুন`, `রাখুন`, `দিন`).
