# Voice fact-check: Linux Networking (round 1, 2026-10-20)

Page: `content/linux/networking.mdx`. I did not write this page.

Method: I read the 15 `<Voices>` blocks. For each claim in a `<Layman>` or `<Bangla>` panel, I found the `<Technical>` sentence of the same `##` section that it restates. A claim that is not in the Technical panel, or that changes a number, a version, a flag, a command, a path, a product name, a scope, or a condition, is a FAIL. An omission is not a FAIL. A script checked that each `<Cite n>` in a voice panel uses a number that the Technical panel of the same section cites, and that each number in a voice panel is in the Technical panel. I then read each cite in its sentence and checked that it is the cite that the Technical panel gives for the same claim. I read the Bangla text for meaning, for polite form (আপনি), for English technical terms, and for the hyphen between an English word and a Bangla suffix. A language problem is a FAIL only if it changes or hides the meaning. The sections have no `Key words` table, so no section is excluded. I did not check the Technical text against its sources. That is in `linux-networking.factcheck.md`.

Result: 0 FAILs. All cites in the voice panels are in the cite set of the Technical panel of the same section. The Bangla text uses the polite form (no তুমি or করো forms). The language notes below are small, and none of them changes the meaning.

Flagged items:

- DHCP, T1 and T2: the Layman and Bangla text opens the pair with "By default", then gives "0.875 of the lease time (T2)" with no own "by default". The reader still sees the default frame, so it is a PASS.
- Subnetting: the Layman text says "broadcast address" and drops "directed". The address (192.0.2.63) and the scope ("every host of the subnet") do not change. PASS.
- File Transfer, `rsync --delete`: the Layman text gives the dry-run advice as an instruction and not as "the manual advises". The cite 62 supports both. PASS.
- The tutorial's own advice in each section is the same in the Technical and in the voice panels. It has no cites in the voice panels, and the same sentences in the Technical panel have none, or have the same cite.
- Language notes (rows with a note): TCP/IP "short connections", ping "পেজ", traceroute "unlikely ports", netstat "stray packets", Packet Analysis "এর user".
