# Voice fact-check: Claude Models (round 1, 2026-10-20)

Page: `content/getting-started/models.mdx`. I did not write the voices of this page.

Method: I read the 8 `<Voices>` blocks. For each claim in a `<Layman>` or `<Bangla>` panel, I found the `<Technical>` sentence of the same `##` section that it restates. A claim that is not in the Technical panel, or that changes a number, a version, a flag, a command, a path, a product name, a scope, or a condition, is a FAIL. An omission is not a FAIL. For each `<Cite n>` in a voice panel, I checked two things. The Technical panel of the same section cites the same `n`. The cite follows a claim that the Technical panel also supports with that `n`. I did not re-check the Technical text against the sources. That is the job of the report of the Technical text. I read the Bangla text for meaning and natural use. I checked that the tone is polite (আপনি), that technical terms stay in English, and that a hyphen joins an English word and a Bangla suffix. A language problem is a FAIL only if it changes or hides the meaning. The page has no "Key words" section.

Flagged items:

- "slowest" for Fable 5.1 (section 1, rows 3 and 17): the Technical table says "Slower". The other three rows say Moderate, Fast, and Fastest. So the ranking "slowest" follows from the table. PASS.
- "read 1M tokens at one time and write up to 128K tokens" (rows 10 and 24): the Technical text says "1M-token context window" and "128K-token maximum output". The gloss is a simple restatement. PASS. A context window holds input and output together, but the gloss does not say otherwise.
- "three places" (section 5, rows 81 and 91): the Technical panel has three `###` parts (session, startup, settings). The Technical order list has five items. No Layman or Bangla claim contradicts the list. PASS, with a language note.
- "example" in section 7 (rows 126 and 130): the Layman and Bangla panels refer to "the example". The code blocks are only in the Technical panel. The facts are the same as the Technical YAML. PASS, with a language note.

## Language notes

These notes do not change the meaning. None is a FAIL.

- Row 67: "default-ভাবে" is stiff. "default হিসেবে" reads better.
- Row 68: the quoted meaning of `inherit` ends in "ব্যবহার করো" (informal). The rest of the Bangla text uses আপনি. "ব্যবহার করুন" fits the tone.
- Rows 81 and 91: "three places" (তিন জায়গা). The same section gives 5 sources in the order list. "three ways" (তিনভাবে) is closer to the three `###` parts of the Technical panel.
- Row 96: "প্রথমটি জেতে" (the first one wins) is colloquial. "প্রথমটি অগ্রাধিকার পায়" is more formal.
- Row 98: "মিলিয়ে" for "matching" can read as "combining". "সংশ্লিষ্ট" is clearer.
- Row 109: "test it first" drops "before adopting it broadly". "test it before you use it widely" keeps the condition. The Bangla text (row 120) keeps it.
- Rows 126 and 130: "In the example" and "উদাহরণে" point to YAML blocks that only the Technical panel shows. A reader of only the Layman or Bangla panel sees no example. "In the example of the Technical text" or a short inline form (`model: sonnet`) would help.
- Row 131: "পেজ" is a transliteration. The rest of the text keeps technical terms in English. "page" would match.
- Row 135: "low-cost work" can read as "cheap work". "cost-sensitive work" (work where cost matters) is the Technical wording.
