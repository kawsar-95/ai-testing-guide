# Voice fact-check: Stateless Service (round 1, 2026-10-20)

Page: `content/architecture/stateless-service.mdx`. I did not write this page.

Method: I read the 5 `<Voices>` blocks. For each claim in a `<Layman>` or `<Bangla>` panel, I found the `<Technical>` sentence of the same `##` section that it restates. A claim that is not in the Technical panel, or that changes a number, a version, a command, a product name, a scope, or a condition, is a FAIL. An omission is not a FAIL. For each `<Cite n>` in a voice panel, I checked that the Technical panel of the same section cites the same `n` for the same claim, and that the source title in `page.sources` fits the claim. I read the Bangla text for meaning, for the polite form (আপনি), for technical terms kept in English, and for the hyphen between an English word and a Bangla suffix. The "Key words" section has no voices.

Notes:

- The Layman and Bangla panels of "In plain words" omit the table row label "Token data" and the long image description. This is an omission, not a FAIL. The image stays in the Technical panel only.
