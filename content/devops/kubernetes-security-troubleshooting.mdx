## What it is

<Voices>
<Technical>

A Secret is an object that contains a small amount of sensitive data such as a password, a token, or a key <Cite n={1} />. By default, Kubernetes Secrets are stored unencrypted in the API server's underlying data store (etcd) <Cite n={1} />.

</Technical>

A Secret is an object that holds a small amount of sensitive data, such as a password, a token, or a key <Cite n={1} />. By default, Kubernetes stores Secrets without encryption. They sit in the data store (etcd) that the API server uses underneath <Cite n={1} />.

</Layman>
