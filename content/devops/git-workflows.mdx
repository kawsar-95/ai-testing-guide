# Git Workflows

Rebase, stash, worktrees, bisect, and cherry-pick. A short explanation with its sources comes first. The reels after it show the topic at work.

<PageMeta />

## What it is

<Voices>
<Technical>

Git has a command for each of these jobs. `git rebase` reapplies commits on top of another base tip <Cite n={1} />. `git stash` stashes the changes in a dirty working directory away <Cite n={2} />. `git worktree` manages multiple working trees attached to the same repository, so you can check out more than one branch at a time <Cite n={3} />. `git bisect` uses binary search to find the commit that introduced a bug <Cite n={4} />. `git cherry-pick` applies the changes introduced by some existing commits <Cite n={5} />.

</Technical>
<Layman>

Git has a command for each of these jobs. `git rebase` applies commits again, on top of another base tip <Cite n={1} />. `git stash` puts away the changes in a dirty working directory <Cite n={2} />. `git worktree` manages several working trees of the same repository. With it, you can check out more than one branch at a time <Cite n={3} />. `git bisect` uses binary search to find the commit that introduced a bug <Cite n={4} />. `git cherry-pick` applies the changes that some existing commits introduced <Cite n={5} />.

</Layman>
<Bangla>

Git-এ এই প্রতিটি কাজের জন্য একটা করে command আছে। `git rebase` commit-গুলো অন্য একটা base tip-এর ওপরে আবার বসায় <Cite n={1} />। `git stash` একটা dirty working directory-র পরিবর্তনগুলো সরিয়ে রাখে <Cite n={2} />। `git worktree` একই repository-র একাধিক working tree পরিচালনা করে। এর সাহায্যে আপনি একসাথে একাধিক branch check out করতে পারেন <Cite n={3} />। `git bisect` binary search ব্যবহার করে সেই commit খুঁজে বের করে, যেটা একটা bug ঢুকিয়েছে <Cite n={4} />। `git cherry-pick` কিছু existing commit-এর আনা পরিবর্তনগুলো প্রয়োগ করে <Cite n={5} />।

</Bangla>
