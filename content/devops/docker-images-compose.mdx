## What it is

<Voices>
<Technical>

A Dockerfile is a text document that contains all the commands a user could call on the command line to assemble an image <Cite n={1} />. Docker Compose is a tool for defining and running multi-container applications <Cite n={2} />. Bake is a feature of Docker Buildx that lets you define your build configuration using a declarative file <Cite n={3} />.

</Technical>
<Layman>

A Dockerfile is a text file. It holds all the commands that a user could run on the command line to assemble an image <Cite n={1} />. Docker Compose is a tool for defining and running applications that have more than one container <Cite n={2} />. Bake is a feature of Docker Buildx. You define your build configuration in a declarative file <Cite n={3} />.

</Layman>
