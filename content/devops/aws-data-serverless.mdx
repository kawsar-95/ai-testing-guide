# AWS Databases and Serverless

AWS Lambda, DynamoDB, Athena, and Step Functions. A short explanation with its sources comes first. The reels after it show the topic at work.

<PageMeta />

## What it is

<Voices>
<Technical>

AWS Lambda is a serverless compute service: you can run code without provisioning or managing servers <Cite n={1} />. Amazon DynamoDB is a serverless, fully managed, distributed NoSQL database <Cite n={2} />. Amazon Athena is an interactive query service that makes it easy to analyze data directly in Amazon S3 using standard SQL <Cite n={3} />. With AWS Step Functions, you can create workflows, also called state machines, to build distributed applications, automate processes, orchestrate microservices, and create data and machine learning pipelines <Cite n={4} />.

</Technical>
