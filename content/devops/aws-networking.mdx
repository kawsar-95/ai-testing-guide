# AWS Networking and Delivery

VPC, Elastic Load Balancing, Route 53, and CloudFront. A short explanation with its sources comes first. The reels after it show the topic at work.

<PageMeta />

## What it is

<Voices>
<Technical>

With Amazon Virtual Private Cloud (Amazon VPC), you can launch AWS resources in a logically isolated virtual network that you have defined <Cite n={1} />. Elastic Load Balancing automatically distributes your incoming traffic across multiple targets <Cite n={2} />. Amazon Route 53 is a highly available and scalable Domain Name System (DNS) web service <Cite n={3} />. Amazon CloudFront is a web service that speeds up distribution of your static and dynamic web content to your users <Cite n={4} />.

</Technical>
<Layman>

With Amazon VPC, you define your own virtual network. It is logically isolated, and you can launch AWS resources in it <Cite n={1} />. Elastic Load Balancing automatically spreads your incoming traffic across several targets <Cite n={2} />. Amazon Route 53 is a DNS (Domain Name System) web service. It is highly available and scalable <Cite n={3} />. Amazon CloudFront is a web service. It speeds up the delivery of your static and dynamic web content to your users <Cite n={4} />.

</Layman>
<Bangla>

Amazon VPC দিয়ে আপনি নিজের virtual network বানান। এটা logically isolated, আর এতে আপনি AWS resource চালু করতে পারেন <Cite n={1} />। Elastic Load Balancing আপনার আসা traffic স্বয়ংক্রিয়ভাবে একাধিক target-এ ভাগ করে দেয় <Cite n={2} />। Amazon Route 53 হলো একটা DNS (Domain Name System) web service। এটা highly available আর scalable <Cite n={3} />। Amazon CloudFront একটা web service। এটা আপনার static ও dynamic web content ব্যবহারকারীদের কাছে পৌঁছানোর গতি বাড়ায় <Cite n={4} />।
