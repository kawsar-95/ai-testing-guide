# Terraform and Infrastructure as Code

Terraform, Packer, and Crossplane. A short explanation with its sources comes first. The reels after it show the topic at work.

## What it is

<Voices>
<Technical>

Terraform is an infrastructure as code tool that lets you build, change, and version cloud and on-prem resources safely and efficiently <Cite n={1} />. Packer is a community tool for creating identical machine images for multiple platforms from a single source configuration <Cite n={2} />. Crossplane is a control plane framework for platform engineering <Cite n={3} />.

</Technical>
