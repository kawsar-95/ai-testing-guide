# AWS Compute and Storage

EC2, S3, and EBS. A short explanation with its sources comes first. The reels after it show the topic at work.

<PageMeta />

## What it is

<Voices>
<Technical>

Amazon Elastic Compute Cloud (Amazon EC2) provides on-demand, scalable computing capacity in the Amazon Web Services (AWS) Cloud <Cite n={1} />. Amazon S3 is an object storage service that stores data as objects, hierarchical data, or tabular data within buckets <Cite n={2} />. An Amazon EBS volume is a durable, block-level storage device that you can attach to your instances <Cite n={3} />.

</Technical>
<Layman>

Amazon EC2 gives you computing capacity in the AWS Cloud. You get it on demand, and it is scalable <Cite n={1} />. Amazon S3 is a storage service for objects. It keeps data in buckets, as objects, hierarchical data, or tabular data <Cite n={2} />. An Amazon EBS volume is a storage device. It is durable, and it works at block level. You can attach it to your instances <Cite n={3} />.

</Layman>
