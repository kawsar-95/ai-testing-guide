# AWS Identity and Security

IAM and IAM roles, KMS, and Secrets Manager. A short explanation with its sources comes first. The reels after it show the topic at work.

<PageMeta />

## What it is

<Voices>
<Technical>

AWS Identity and Access Management (IAM) is a web service that helps you securely control access to AWS resources <Cite n={1} />. An IAM role is an IAM identity that you can create in your account that has specific permissions <Cite n={2} />. AWS Key Management Service (AWS KMS) is an AWS managed service that makes it easy for you to create and control the keys used to encrypt and sign your data <Cite n={3} />, and AWS Secrets Manager helps you manage, retrieve, and rotate database credentials, application credentials, OAuth tokens, API keys, and other secrets throughout their lifecycles <Cite n={4} />.

</Technical>
<Layman>

AWS IAM is a web service. It helps you control access to AWS resources, and to do it securely <Cite n={1} />. An IAM role is an identity that you can create in your account. It has specific permissions <Cite n={2} />. AWS KMS is a service that AWS manages. It makes it easy to create and control the keys that encrypt and sign your data <Cite n={3} />. AWS Secrets Manager helps you manage, retrieve, and rotate secrets: database credentials, application credentials, OAuth tokens, API keys, and others. It does this throughout their lifecycles <Cite n={4} />.

</Layman>
<Bangla>

AWS IAM হলো একটা web service। এটা AWS resource-এ প্রবেশাধিকার নিরাপদে নিয়ন্ত্রণ করতে আপনাকে সাহায্য করে <Cite n={1} />। IAM role হলো একটা identity, যা আপনি নিজের account-এ তৈরি করতে পারেন। এর নির্দিষ্ট permission আছে <Cite n={2} />। AWS KMS এমন একটা service, যা AWS পরিচালনা করে। এটা আপনার data encrypt ও sign করার key তৈরি ও নিয়ন্ত্রণ করা সহজ করে <Cite n={3} />। AWS Secrets Manager আপনাকে secret manage, retrieve ও rotate করতে সাহায্য করে: database credential, application credential, OAuth token, API key এবং অন্যান্য secret। এটা তাদের পুরো lifecycle জুড়ে কাজ করে <Cite n={4} />।
