## What it is

<Voices>
<Technical>

Observability lets you understand a system from the outside by letting you ask questions about that system without knowing its inner workings <Cite n={1} />. Prometheus is an open-source systems monitoring and alerting toolkit <Cite n={2} />. Loki is a horizontally-scalable, highly-available, multi-tenant log aggregation system inspired by Prometheus <Cite n={3} />.

</Technical>
<Layman>

Observability lets you understand a system from the outside. You can ask questions about the system without knowing how it works inside <Cite n={1} />. Prometheus is an open-source toolkit for monitoring and alerting on systems <Cite n={2} />. Loki is a log aggregation system. It is horizontally scalable, highly available, and multi-tenant. Prometheus inspired it <Cite n={3} />.

</Layman>

Observability আপনাকে একটা system বাইরে থেকে বুঝতে দেয়। ভেতরে কীভাবে কাজ হয় তা না জেনেও আপনি system সম্পর্কে প্রশ্ন করতে পারেন <Cite n={1} />। Prometheus হলো system monitoring ও alerting-এর একটা open-source toolkit <Cite n={2} />। Loki হলো একটা log aggregation system। এটা horizontally scalable, highly available ও multi-tenant। Prometheus থেকে এটার অনুপ্রেরণা এসেছে <Cite n={3} />।
