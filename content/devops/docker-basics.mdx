## What it is

<Voices>
<Technical>

Docker is an open platform for developing, shipping, and running applications <Cite n={1} />. Docker enables you to separate your applications from your infrastructure so you can deliver software quickly <Cite n={1} />. Docker is lightweight and fast. It provides a viable, cost-effective alternative to hypervisor-based virtual machines <Cite n={1} />.

</Technical>
<Layman>

Docker is an open platform. You use it to develop, ship, and run applications <Cite n={1} />. Docker lets you keep your applications apart from your infrastructure.
