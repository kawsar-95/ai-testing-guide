# Kubernetes Networking and Storage

Services, DNS records, and volumes. A short explanation with its sources comes first. The reels after it show the topic at work.

<PageMeta />

## What it is

<Voices>
<Technical>

In Kubernetes, a Service is a method for exposing a network application that is running as one or more Pods in your cluster <Cite n={1} />. Kubernetes creates DNS records for Services and Pods <Cite n={2} />. On-disk files in a container are ephemeral <Cite n={3} />. One problem occurs when a container crashes or is stopped; the container state is not saved, so all of the files that were created or modified during the lifetime of the container are lost <Cite n={3} />. Another problem occurs when multiple containers are running in a Pod and need to share files <Cite n={3} />. The Kubernetes volume abstraction can help you to solve both of these problems <Cite n={3} />.

</Technical>
<Layman>

A Service is a way to expose a network application. The application runs as one or more Pods in your cluster <Cite n={1} />. Kubernetes creates DNS records for Services and Pods <Cite n={2} />. Files that a container keeps on its disk are ephemeral. They do not last <Cite n={3} />. Problem one: when a container crashes or is stopped, its state is not saved. All the files that it created or changed while it ran are lost <Cite n={3} />. Problem two happens when multiple containers run in one Pod and need to share files <Cite n={3} />. The Kubernetes volume abstraction can help you solve both problems <Cite n={3} />.

</Layman>
<Bangla>

Service হলো একটা network application প্রকাশ (expose) করার উপায়। application-টা আপনার cluster-এ এক বা একাধিক Pod হিসেবে চলে <Cite n={1} />। Kubernetes Service ও Pod-এর জন্য DNS record তৈরি করে <Cite n={2} />। Container disk-এ যে file রাখে, সেগুলো ephemeral (অস্থায়ী), অর্থাৎ টেকে না <Cite n={3} />। প্রথম সমস্যা: container crash করলে বা বন্ধ হলে তার state সংরক্ষিত হয় না। চলার সময় সে যেসব file তৈরি বা পরিবর্তন করেছিল, সব হারিয়ে যায় <Cite n={3} />। দ্বিতীয় সমস্যা হয় যখন একটা Pod-এ একাধিক container চলে এবং তাদের file share করতে হয় <Cite n={3} />। Kubernetes volume abstraction এই দুটি সমস্যাই সমাধান করতে সাহায্য করতে পারে <Cite n={3} />।
