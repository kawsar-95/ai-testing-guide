## What it is

<Voices>
<Technical>

Pods are the smallest deployable units of computing that you can create and manage in Kubernetes <Cite n={1} />. A ReplicaSet's purpose is to maintain a stable set of replica Pods running at any given time <Cite n={2} />. A Deployment provides declarative updates for Pods and ReplicaSets <Cite n={3} />.
