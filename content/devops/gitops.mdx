## What it is

<Voices>
<Technical>

OpenGitOps is a set of open-source standards, best practices, and community-focused education that helps organizations adopt a structured, standardized approach to implementing GitOps <Cite n={1} />. A system managed by GitOps must have its desired state expressed declaratively <Cite n={1} />. Desired state is stored in a way that enforces immutability, versioning and retains a complete version history <Cite n={1} />. Software agents automatically pull the desired state declarations from the source <Cite n={1} />. Software agents continuously observe actual system state and attempt to apply the desired state <Cite n={1} />. Two GitOps tools for Kubernetes are Argo CD, a declarative, GitOps continuous delivery tool <Cite n={2} />, and Flux, a tool for keeping Kubernetes clusters in sync with sources of configuration (like Git repositories) <Cite n={3} />.

</Technical>
<Layman>

OpenGitOps is a set of open-source standards, best practices, and education for the community. It helps organizations adopt a structured, standard way to do GitOps <Cite n={1} />. A system managed by GitOps must have its desired state expressed declaratively <Cite n={1} />. The desired state is stored in a way that enforces immutability and versioning, and it keeps a complete version history <Cite n={1} />. Software agents pull the declared desired state from the source by themselves <Cite n={1} />. Software agents keep watching the actual state of the system and try to apply the desired state <Cite n={1} />. Two GitOps tools for Kubernetes are Argo CD, a declarative, GitOps continuous delivery tool <Cite n={2} />, and Flux, a tool for keeping Kubernetes clusters in sync with sources of configuration, like Git repositories <Cite n={3} />.

</Layman>
