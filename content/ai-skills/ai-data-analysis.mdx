# AI Data Analysis

Test runs make a lot of data: pass and fail counts, run times, retries, and bug reports. AI data analysis lets you ask questions of that data in plain words. The answer is only useful after you check one number by hand.

<PageMeta />

## In plain words

<Voices>
<Technical>

**AI data analysis** means that you upload a data file, such as a CSV export of test results, and ask questions about it in plain words. The AI tool answers with a number, a table, or a chart.

Behind the answer there is usually code. OpenAI's Code Interpreter lets a model write and run Python code in a sandbox <Cite n={1} />. Claude can also write Python scripts for data analysis <Cite n={2} />. In Google Sheets, Gemini works in a side panel, where you pick a suggested prompt or write your own <Cite n={3} />.

The skill has two halves: ask a precise question, and then prove that the answer is right. AI tools can be wrong. Google's own help says that Gemini features may suggest inaccurate information <Cite n={3} />.

</Technical>
<Layman>

**AI data analysis** means that you upload a data file and ask questions about it in plain words. An example is a CSV export of test results. The AI tool answers with a number, a table, or a chart.

এই দক্ষতার দুটো অংশ। প্রথমে একটা স্পষ্ট প্রশ্ন করুন। তারপর প্রমাণ করুন উত্তরটা সঠিক। AI টুল ভুল করতে পারে। Google-এর নিজের হেল্প বলে Gemini ফিচার ভুল তথ্য দিতে পারে <Cite n={3} />।

## How it works

<Voices>
<Technical>

A typical flow has four steps:

```text
CSV / sheet --> your question --> AI writes code --> code runs --> answer + chart
                                       ^                              |
                                       +---- you read the code -------+
```

1. **Load the data.** Code Interpreter can process data files, and `.csv` is a supported type <Cite n={1} />. Claude accepts CSV, TSV, and other files for analysis and charts <Cite n={2} />.
2. **Ask.** For example: "Group the failed tests by suite and count them."
3. **Run.** The tool writes code and runs it. Claude can make charts as image files such as PNG <Cite n={2} />. Code Interpreter can make files with data and images of graphs <Cite n={1} />.
4. **Check.** In Sheets, you can open the analysis steps that Gemini used <Cite n={3} />. In tools that show the code, read it.

Sheets also has a cell formula, `=AI("prompt", [range])` <Cite n={4} />. It can sort text into groups, which includes sentiment analysis, and it can pull key takeaways from the sheet <Cite n={4} />. This is useful for free-text bug titles.

One detail matters for reports: a chart that Gemini inserts in Sheets does not update when the source data changes <Cite n={3} />.

</Technical>

A typical flow has four steps. You give data and a question. The AI writes code. The code runs. You get an answer and a chart, and you read how it got there.

1. **ডেটা লোড করুন।** Code Interpreter ডেটা ফাইল নিয়ে কাজ করতে পারে, এবং `.csv` একটা সমর্থিত টাইপ <Cite n={1} />। Claude অ্যানালাইসিস ও চার্টের জন্য CSV, TSV ও অন্য ফাইল নেয় <Cite n={2} />।
2. **প্রশ্ন করুন।** যেমন: "ফেল করা টেস্টগুলো suite অনুযায়ী ভাগ করে গোনো।"
3. **চালান।** টুল কোড লিখে চালায়। Claude PNG-এর মতো ইমেজ ফাইলে চার্ট বানাতে পারে <Cite n={2} />। Code Interpreter ডেটা ও গ্রাফের ছবিসহ ফাইল বানাতে পারে <Cite n={1} />।
4. **যাচাই করুন।** Sheets-এ আপনি Gemini-র ব্যবহার করা analysis steps খুলে দেখতে পারেন <Cite n={3} />। টুল কোড দেখালে সেটা পড়ুন।

Sheets-এ একটা সেল ফর্মুলাও আছে: `=AI("prompt", [range])` <Cite n={4} />। এটা টেক্সটকে গ্রুপে ভাগ করতে পারে, যার মধ্যে sentiment analysis-ও আছে। শিট থেকে মূল পয়েন্টও বের করতে পারে <Cite n={4} />। ফ্রি-টেক্সট বাগ টাইটেলের জন্য এটা কাজের।

রিপোর্টের জন্য একটা খুঁটিনাটি জরুরি। Gemini Sheets-এ যে চার্ট বসায়, সোর্স ডেটা বদলালে তা আপডেট হয় না <Cite n={3} />।

## How a tester uses it

<Voices>
<Technical>

- **Test results.** Export a run as CSV and ask: "Which suites have the lowest pass rate? Show a bar chart." Then compare the chart with the totals in your CI report.
- **Flaky-test data.** Export many runs of the same commit. Ask for tests that both passed and failed, and for their failure messages. A test that changes result with no code change is a flaky candidate.
- **Defect trends.** Export bugs with created date, severity, and component. Ask for counts per component per month. Use `=AI()` to group free-text titles <Cite n={4} />, then check a sample of the groups yourself.
- **Performance results.** Load a k6 summary export and ask for the slowest endpoints. The [k6 module](/k6/) explains what the metrics mean.

<Callout type="tip" title="Tutorial advice">
This is the tutorial's own advice. Before you share any AI number, check one number by hand. Filter the raw file yourself and count one value, for example the failures of one suite. If your count and the AI count differ, do not share the report until you know why.
</Callout>

</Technical>

- **Test results.** Export a run as CSV. Ask: "Which suites have the lowest pass rate? Show a bar chart." Then compare the chart with the totals in your CI report.

<Bangla>

- **টেস্ট রেজাল্ট।** একটা রান CSV হিসেবে এক্সপোর্ট করুন। জিজ্ঞেস করুন: "কোন suite-এর pass rate সবচেয়ে কম? একটা bar chart দেখাও।" তারপর চার্টটা আপনার CI রিপোর্টের মোট সংখ্যার সাথে মেলান।
- **Flaky-test ডেটা।** একই commit-এর অনেকগুলো রান এক্সপোর্ট করুন। যেসব টেস্ট পাসও করেছে আবার ফেলও করেছে, সেগুলো ও তাদের failure message চান। কোড না বদলেও যে টেস্টের ফল বদলায়, সেটা flaky হতে পারে।
- **ডিফেক্টের ট্রেন্ড।** তৈরির তারিখ, severity ও component-সহ বাগগুলো এক্সপোর্ট করুন। প্রতি মাসে প্রতি component-এ কতগুলো, তা চান। ফ্রি-টেক্সট টাইটেল গ্রুপ করতে `=AI()` ব্যবহার করুন <Cite n={4} />। তারপর কিছু গ্রুপ নিজে যাচাই করুন।
- **পারফরম্যান্স রেজাল্ট।** একটা k6 summary export লোড করুন। সবচেয়ে ধীর endpoint-গুলো চান। মেট্রিকগুলোর মানে [k6 module](/k6/)-এ আছে।

এটা টিউটোরিয়ালের নিজের পরামর্শ। AI-এর কোনো সংখ্যা শেয়ার করার আগে একটা সংখ্যা নিজে হাতে মিলিয়ে নিন। মূল ফাইলটা নিজে ফিল্টার করে একটা মান গুনুন, যেমন একটা suite-এর failure। আপনার গোনা আর AI-এর গোনা আলাদা হলে, কারণ না জানা পর্যন্ত রিপোর্ট শেয়ার করবেন না।

## Common mistakes

<Voices>
<Technical>

- **Sharing an unchecked number.** The tool can be wrong <Cite n={3} />. Fix: count one value by hand from the raw file.
- **A vague question.** "Analyze this" gives a vague answer. Fix: name the columns, the filter, and the output, for example "count rows where status is failed, grouped by suite".
- **A stale chart in a report.** A Gemini chart in Sheets does not follow later data changes <Cite n={3} />. Fix: make the chart again after each new export, and write the export date on it.
- **Uploading private data.** Test exports can hold user emails or tokens in error messages. Fix: remove those columns first, and check your company's rules on [AI Governance](/ai-skills/ai-governance/).
- **Ignoring hidden instructions.** Claude's help warns that hidden instructions in files can try to trick it, and asks you to monitor it while it works <Cite n={2} />. Fix: only load files from sources you trust, and watch what the tool does.

</Technical>
<Layman>

- **Sharing a number that nobody checked.** The tool can be wrong <Cite n={3} />. Fix: count one value by hand from the raw file.
- **A vague question.** "Analyze this" gives a vague answer. Fix: name the columns, the filter, and the output. For example: "count rows where status is failed, grouped by suite".
- **An old chart in a report.** A Gemini chart in Sheets does not follow later data changes <Cite n={3} />. Fix: make the chart again after each new export. Write the export date on it.
- **Uploading private data.** Test exports can hold user emails or tokens in error messages. Fix: remove those columns first. Check the rules of your company in [AI Governance](/ai-skills/ai-governance/).
- **Missing hidden instructions.** Claude's help warns that hidden instructions in files can try to trick it. It asks you to watch Claude while it works <Cite n={2} />. Fix: only load files from sources that you trust. Watch what the tool does.

</Layman>
<Bangla>

- **যাচাই না করা সংখ্যা শেয়ার করা।** টুল ভুল করতে পারে <Cite n={3} />। সমাধান: মূল ফাইল থেকে একটা মান হাতে গুনুন।
- **অস্পষ্ট প্রশ্ন।** "এটা analyze করো" বললে অস্পষ্ট উত্তর আসে। সমাধান: কলাম, ফিল্টার ও আউটপুট বলে দিন। যেমন: "status failed এমন row গোনো, suite অনুযায়ী ভাগ করে।"
- **রিপোর্টে পুরোনো চার্ট।** Sheets-এ Gemini-র চার্ট পরের ডেটা পরিবর্তন অনুসরণ করে না <Cite n={3} />। সমাধান: প্রতিটা নতুন এক্সপোর্টের পরে চার্ট আবার বানান। এক্সপোর্টের তারিখ চার্টে লিখুন।
- **ব্যক্তিগত ডেটা আপলোড করা।** টেস্ট এক্সপোর্টের error message-এ ইউজারের ইমেইল বা টোকেন থাকতে পারে। সমাধান: আগে ওই কলামগুলো সরান। কোম্পানির নিয়ম [AI Governance](/ai-skills/ai-governance/)-এ দেখুন।

## How to start

<Voices>
<Technical>

1. Export the results of your last 10 CI runs as one CSV file. Remove names, emails, and tokens.
2. Upload it to a tool your company allows, and ask one precise question, such as "failures per suite".
3. Read the code or the analysis steps that the tool shows <Cite n={3} />.
4. Count one value by hand in the raw file, and compare.
5. Save the question as a reusable prompt. See [Prompting](/ai-skills/prompting/) for how to make it precise.

</Technical>
<Layman>

1. Export the results of your last 10 CI runs as one CSV file. Remove names, emails, and tokens.
2. Upload it to a tool that your company allows. Ask one clear question, such as "failures per suite".
3. Read the code or the analysis steps that the tool shows <Cite n={3} />.
4. Count one value by hand in the raw file. Compare the two.
5. Save the question as a prompt that you can use again. See [Prompting](/ai-skills/prompting/) to make it clear.

</Layman>
<Bangla>

1. আপনার শেষ ১০টা CI রানের রেজাল্ট একটা CSV ফাইলে এক্সপোর্ট করুন। নাম, ইমেইল ও টোকেন সরিয়ে দিন।
