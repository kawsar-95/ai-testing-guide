# Image Generation

An image model makes a picture from a text description. It is a specialist skill. Learn it when your team ships creative work every week, such as banners, product shots, or app screens, and wants faster first drafts.

<PageMeta />

## In plain words

<Voices>
<Technical>

You write a description (a prompt), and the model returns an image. Some image APIs, such as the OpenAI Image API, can also edit an image: you give an image and a new prompt, and the model changes part of it or all of it <Cite n={1} />.

**The trigger for this skill:** creative work ships every week. A design or marketing team that makes many images can save time on drafts. A team that needs one logo a year does not need this skill.

Testers meet image generation in two ways:

- **As a tool.** You make synthetic images for test data: upload tests, image-processing features, and edge cases that are hard to photograph.
- **As a feature under test.** The product itself makes images for users. Then you test the output, the safety filters, and the provenance data, and you check that users can see that an image is AI-made.

Image models have known limits. A vendor guide says that its model can still struggle with exact text in an image, with the same character across many images, and with exact layouts <Cite n={1} />. Plan your tests around these limits.

</Technical>

## How it works

<Voices>
<Technical>

Many image models are **diffusion models**. The DDPM paper describes them as models that build the output step by step, like a gradual decompression <Cite n={8} />. The Hugging Face Diffusers library gives pretrained diffusion models for images, video, and audio <Cite n={7} />. Its `DiffusionPipeline` runs a model in a few lines and can load adapters such as LoRA <Cite n={7} />. Offloading and quantization let large models run on machines with little memory <Cite n={7} />.

A hosted API hides these steps. With the OpenAI Image API, you send a prompt and get a file back. The default format is `png`, and `jpeg` and `webp` are also possible <Cite n={1} />. Common sizes are 1024x1024, 1536x1024, and 1024x1536, and some models also allow custom sizes <Cite n={1} />. A complex prompt can take up to 2 minutes <Cite n={1} />, so set long timeouts in tests.

```text
prompt --> safety filter --> image model --> safety filter --> image file
                                                      |
                                                      +--> marks: watermark and/or
                                                           signed provenance data
```

**Safety filters.** The OpenAI API filters all prompts and all generated images by its content policy <Cite n={1} />. A `moderation` parameter has two values, `auto` (the default) and `low` <Cite n={1} />. A blocked request returns an error with the code `moderation_blocked` <Cite n={1} />.

**Marks on the image.** There are two kinds:

- A **watermark** is hidden in the pixels. Google SynthID puts watermarks that people cannot see into AI-made images, audio, text, and video <Cite n={3} />. All images from the Gemini API carry a SynthID watermark <Cite n={2} />.
- **Content Credentials** are signed metadata from the C2PA standard, an open standard that records the origin and the edits of a file <Cite n={4} />. A C2PA manifest holds statements about the file and is digitally signed, so a change to it can be detected <Cite n={5} />.

</Technical>

<Bangla>

অনেক image মডেল হলো **diffusion মডেল**। DDPM পেপার বলে এরা ধাপে ধাপে আউটপুট বানায়, ধীরে ধীরে খুলে দেওয়ার মতো <Cite n={8} />। Hugging Face Diffusers লাইব্রেরি ছবি, ভিডিও আর অডিওর জন্য ট্রেইন করা diffusion মডেল দেয় <Cite n={7} />। এর `DiffusionPipeline` কয়েক লাইনে একটা মডেল চালায়। এটা LoRA-এর মতো adapter লোড করতে পারে <Cite n={7} />। Offloading আর quantization কম মেমরির মেশিনেও বড় মডেল চালাতে দেয় <Cite n={7} />।

একটা hosted API এই ধাপগুলো লুকিয়ে রাখে। OpenAI Image API-তে আপনি একটা প্রম্পট পাঠান আর একটা ফাইল ফেরত পান। ডিফল্ট ফরম্যাট `png`। `jpeg` আর `webp`-ও সম্ভব <Cite n={1} />। প্রচলিত সাইজ হলো 1024x1024, 1536x1024 আর 1024x1536। কিছু মডেলে নিজের পছন্দের সাইজও চলে <Cite n={1} />। একটা জটিল প্রম্পটে ২ মিনিট পর্যন্ত লাগতে পারে <Cite n={1} />। তাই টেস্টে লম্বা timeout দিন।

ধাপগুলো এমন। প্রম্পট একটা safety ফিল্টারের মধ্য দিয়ে যায়। মডেল ছবি বানায়। ছবিটা একটা safety ফিল্টারের মধ্য দিয়ে যায়। তারপর আপনি ফাইলটা পান। ফাইলে একটা watermark, ছবির উৎসের সাইন করা ডেটা, বা দুটোই থাকতে পারে।

**Safety ফিল্টার।** OpenAI API তার content policy অনুযায়ী সব প্রম্পট আর সব ছবি ফিল্টার করে <Cite n={1} />। একটা `moderation` প্যারামিটারের দুটো মান আছে: `auto` (ডিফল্ট) আর `low` <Cite n={1} />। ব্লক হওয়া রিকুয়েস্ট `moderation_blocked` কোড সহ একটা এরর ফেরত দেয় <Cite n={1} />।

**ছবির ওপর চিহ্ন।** দুই ধরনের আছে:

- একটা **watermark** পিক্সেলের ভেতরে লুকানো থাকে। Google SynthID AI-এর বানানো ছবি, অডিও, টেক্সট আর ভিডিওতে এমন watermark বসায়, যা মানুষ দেখতে পায় না <Cite n={3} />। Gemini API-এর সব ছবিতে একটা SynthID watermark থাকে <Cite n={2} />।
- **Content Credentials** হলো C2PA স্ট্যান্ডার্ডের সাইন করা ডেটা। C2PA একটা ওপেন স্ট্যান্ডার্ড, যা রেকর্ড রাখে একটা ফাইল কোথা থেকে এসেছে আর কীভাবে এডিট হয়েছে <Cite n={4} />। একটা C2PA manifest ফাইলটা সম্পর্কে কিছু বক্তব্য রাখে। এটা ডিজিটালি সাইন করা, তাই এতে কোনো পরিবর্তন হলে ধরা যায় <Cite n={5} />।

## How a tester uses it

<Voices>
<Technical>

1. **Make upload and image-processing test data.** Generate images in each format and size that the product must accept: `png`, `jpeg`, and `webp` <Cite n={1} />, square, wide, and tall <Cite n={1} />. Add the cases that real photos rarely give you: a very dark scene, a busy background, a tiny object. Keep the generated files in the repo, so that every test run uses the same input.
2. **Make visual test inputs for AI features.** If the product reads images (receipts, ID-like documents, product photos), generated images can cover the rare cases. Do not trust a generated image to hold exact text: the model can still get text placement and clarity wrong <Cite n={1} />. Check every generated input by eye, or add the text yourself with an image tool.
3. **Test the image feature of the product.** Check the safety path: a prompt that the filter blocks must give the user a clear message, not a crash <Cite n={1} />. Check timeouts against the long generation time <Cite n={1} />. For screenshots of the result page, see [Browser Testing with Playwright](/automate/playwright/).
4. **Test provenance and disclosure.** If the product adds Content Credentials, read them with c2patool, a command-line tool for C2PA manifests <Cite n={6} />. Then edit, resize, or re-save the file and check what happens to the credentials <Cite n={5} />. Check that the user interface tells people that the image is AI-made.

<Callout type="tip" title="Tutorial advice">
This is the tutorial's own advice. Never generate images of real people, real customers, or real ID documents for test data. Use clearly fake faces, names, and numbers, and label the files as synthetic in their names, for example `synthetic-receipt-01.png`.
</Callout>

</Technical>

2. **AI ফিচারের জন্য ভিজ্যুয়াল টেস্ট ইনপুট বানান।** প্রোডাক্ট হয়তো ছবি পড়ে, যেমন রসিদ, আইডির মতো ডকুমেন্ট, বা প্রোডাক্টের ছবি। বানানো ছবি দিয়ে বিরল কেসগুলো কভার করা যায়। কিন্তু বানানো ছবির ভেতরের লেখা নিখুঁত হবে, এটা ধরে নেবেন না। মডেল এখনো লেখা ভুল জায়গায় বসাতে বা অস্পষ্ট করতে পারে <Cite n={1} />। প্রতিটা বানানো ইনপুট চোখে দেখে চেক করুন, অথবা একটা ইমেজ টুল দিয়ে লেখাটা নিজে বসান।
3. **প্রোডাক্টের ছবি বানানোর ফিচার টেস্ট করুন।** Safety পথ চেক করুন। ফিল্টার যে প্রম্পট ব্লক করে, তাতে ইউজার একটা পরিষ্কার মেসেজ পাবে, ক্র্যাশ নয় <Cite n={1} />। মডেল যে লম্বা সময় নিতে পারে, তার সাথে timeout মিলিয়ে চেক করুন <Cite n={1} />। ফলাফলের পেজের স্ক্রিনশটের জন্য [Browser Testing with Playwright](/automate/playwright/) দেখুন।
4. **উৎসের ডেটা আর লেবেল টেস্ট করুন।** প্রোডাক্ট হয়তো Content Credentials যোগ করে। C2PA manifest-এর জন্য একটা command-line টুল c2patool দিয়ে সেগুলো পড়ুন <Cite n={6} />। তারপর ফাইলটা এডিট করুন, সাইজ বদলান বা আবার সেভ করুন, আর দেখুন credentials-এর কী হয় <Cite n={5} />। স্ক্রিন যেন মানুষকে জানায় যে ছবিটা AI-এর বানানো, সেটা চেক করুন।

এটা টিউটোরিয়ালের নিজের পরামর্শ। টেস্ট ডেটার জন্য কখনো আসল মানুষ, আসল কাস্টমার বা আসল আইডি ডকুমেন্টের ছবি বানাবেন না। স্পষ্টভাবে নকল মুখ, নাম আর নম্বর ব্যবহার করুন। ফাইলের নামে "synthetic" রাখুন, যেমন `synthetic-receipt-01.png`।

</Bangla>
</Voices>

## Common mistakes

<Voices>
<Technical>

- **Trusting text in a generated image.** A test receipt shows the wrong total, and the test checks the wrong value. Fix: check generated text by eye, or add it yourself <Cite n={1} />.
- **"No credentials" means "real photo".** Adding provenance is optional, and a missing credential proves nothing <Cite n={5} />. Provenance alone also cannot say if the content is true <Cite n={5} />. Fix: treat credentials as one signal, not as proof.
- **Testing provenance only on the fresh file.** Credentials can be removed from a file <Cite n={5} />. Fix: test the full path: upload, resize, compress, download, and share.
- **No label for users.** The product shows AI images with no sign that they are AI-made. Fix (the tutorial's advice): test that each AI image has a visible label, and ask your governance team about the rules. See [AI Governance](/ai-skills/ai-governance/) and [Voice and Avatars](/ai-skills/voice-and-avatars/).
- **Short timeouts.** Tests fail at random because generation is slow <Cite n={1} />. Fix: set timeouts for the slowest case, and mock the image API in fast unit tests.

</Technical>
<Layman>

- **Trusting text in a made image.** A test receipt shows the wrong total, and the test checks the wrong value. Fix: check the text in the image by eye, or add it yourself <Cite n={1} />.
- **"No credentials" means "real photo".** Adding source data is optional. A missing credential proves nothing <Cite n={5} />. Source data alone also cannot say if the content is true <Cite n={5} />. Fix: treat credentials as one sign, not as proof.
- **Testing source data only on the new file.** Credentials can be removed from a file <Cite n={5} />. Fix: test the full path: upload, resize, compress, download, and share.
- **No label for users.** The product shows AI images with no sign that they are made by AI. Fix (the tutorial's advice): test that each AI image has a label that people can see. Ask your governance team about the rules. See [AI Governance](/ai-skills/ai-governance/) and [Voice and Avatars](/ai-skills/voice-and-avatars/).
- **Short timeouts.** Tests fail at random because making an image is slow <Cite n={1} />. Fix: set timeouts for the slowest case. Use a fake image API in fast unit tests.

</Layman>
<Bangla>

- **বানানো ছবির লেখায় ভরসা করা।** একটা টেস্ট রসিদে ভুল মোট টাকা দেখায়, আর টেস্ট ভুল মান চেক করে। সমাধান: ছবির লেখা চোখে দেখে চেক করুন, অথবা নিজে বসান <Cite n={1} />।
- **"Credentials নেই" মানে "আসল ছবি"।** উৎসের ডেটা যোগ করা ঐচ্ছিক। Credential না থাকা কিছুই প্রমাণ করে না <Cite n={5} />। শুধু উৎসের ডেটা দিয়ে কনটেন্ট সত্য কিনা তা-ও বলা যায় না <Cite n={5} />। সমাধান: credentials-কে একটা সংকেত হিসেবে দেখুন, প্রমাণ হিসেবে নয়।
- **শুধু নতুন ফাইলে উৎসের ডেটা টেস্ট করা।** একটা ফাইল থেকে credentials সরিয়ে ফেলা যায় <Cite n={5} />। সমাধান: পুরো পথ টেস্ট করুন: আপলোড, সাইজ বদল, কমপ্রেস, ডাউনলোড আর শেয়ার।
- **ইউজারের জন্য কোনো লেবেল নেই।** প্রোডাক্ট AI ছবি দেখায়, কিন্তু সেগুলো যে AI-এর বানানো তার কোনো চিহ্ন নেই। সমাধান (টিউটোরিয়ালের পরামর্শ): প্রতিটা AI ছবিতে চোখে পড়ার মতো একটা লেবেল আছে কিনা টেস্ট করুন। নিয়মের ব্যাপারে আপনার গভর্নেন্স টিমকে জিজ্ঞেস করুন। [AI Governance](/ai-skills/ai-governance/) আর [Voice and Avatars](/ai-skills/voice-and-avatars/) দেখুন।
- **ছোট timeout।** ছবি বানাতে সময় লাগে বলে টেস্ট এলোমেলোভাবে ফেল করে <Cite n={1} />। সমাধান: সবচেয়ে ধীর কেসের মাপে timeout দিন। দ্রুত unit test-এ একটা নকল image API ব্যবহার করুন।

</Bangla>
</Voices>

## How to start

<Voices>
<Technical>

1. List the image inputs that your product accepts: formats, sizes, and content types.
2. Write one prompt for each missing test case, and generate the images in the formats that you need <Cite n={1} />.
3. Check each image by eye. Fix or remove any image with wrong text <Cite n={1} />.
4. Save the images in the repo with "synthetic" in the file name, and use them in your upload tests.
5. If the product makes images, add tests for a blocked prompt and a slow answer <Cite n={1} />, and for the visible AI label.
6. If the product signs images, read one file with c2patool <Cite n={6} />, then resize it and read it again <Cite n={5} />.

</Technical>

</Layman>

2. প্রতিটা না-থাকা টেস্ট কেসের জন্য একটা প্রম্পট লিখুন। দরকারি ফরম্যাটে ছবি বানান <Cite n={1} />।
3. প্রতিটা ছবি চোখে দেখে চেক করুন। ভুল লেখা থাকা ছবি ঠিক করুন বা বাদ দিন <Cite n={1} />।
4. ফাইলের নামে "synthetic" রেখে ছবিগুলো repo-তে সেভ করুন। আপনার আপলোড টেস্টে এগুলো ব্যবহার করুন।
5. প্রোডাক্ট যদি ছবি বানায়, তাহলে ব্লক হওয়া প্রম্পট আর ধীর উত্তরের টেস্ট যোগ করুন <Cite n={1} />, আর চোখে পড়ার মতো AI লেবেলেরও।
6. প্রোডাক্ট যদি ছবিতে সাইন করে, তাহলে c2patool দিয়ে একটা ফাইল পড়ুন <Cite n={6} />। তারপর সাইজ বদলে আবার পড়ুন <Cite n={5} />।

## Key words

| Word | Meaning |
|---|---|
| Image generation | Making an image from a text prompt, or editing an image with a prompt <Cite n={1} /> |
| Diffusion model | A model that builds its output step by step <Cite n={8} />, run with libraries such as Diffusers <Cite n={7} /> |
| Watermark | A mark hidden in the content that people cannot see, such as SynthID <Cite n={3} /> |
| C2PA | An open standard to record the origin and edits of digital content <Cite n={4} /> |
| Content Credentials | A signed C2PA manifest with statements about a file <Cite n={5} /> |
| Tamper-evident | A change to the signed data can be detected <Cite n={5} /> |
| Synthetic test data | Test inputs that a tool made, not data from real people or events |
