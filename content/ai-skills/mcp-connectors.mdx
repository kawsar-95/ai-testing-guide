# MCP Connectors

An AI assistant that cannot see your browser, your bug tracker, or your test database can only guess. A connector gives it a door into one of those systems. The Model Context Protocol (MCP) is the common shape of that door, so one connector works in many AI apps.

<PageMeta />

## In plain words

<Voices>
<Technical>

The **Model Context Protocol** (MCP) is an open-source standard that links AI apps to outside systems <Cite n={1} />. With MCP, an AI app can reach data sources such as files and databases, tools such as search engines, and workflows such as ready-made prompts <Cite n={1} />. The MCP docs compare it to a USB-C port: one standard way to plug things in <Cite n={1} />.

Many apps support it, among them Claude, ChatGPT, Visual Studio Code, and Cursor <Cite n={1} />. So a team can build or install a connector one time and use it in more than one tool.

In daily speech, a **connector** is an MCP server that you add to your AI app. The protocol itself calls the parts host, client, and server, as the next section shows. This page is about using connectors in testing work. The site's [MCP](/extend/mcp/) page shows the Claude Code setup step by step.

## How it works

<Voices>
<Technical>

MCP has three roles <Cite n={2} />:

- The **host** is the AI application, for example Claude Code.
- The host makes one **client** for each server. Each client keeps its own connection to its server.
- The **server** is a program that provides context to the client.

```text
Claude Code (host)
  +-- client 1 --stdio-------------> Playwright server (your machine)
  +-- client 2 --Streamable HTTP---> issue tracker server (remote)
  +-- client 3 --stdio-------------> test database server (your machine)
```

The messages use JSON-RPC 2.0 <Cite n={2} />. There are two transports. **stdio** connects two processes on the same machine. **Streamable HTTP** connects to a remote server and accepts bearer tokens, API keys, or custom headers for auth. For the tokens, MCP recommends OAuth <Cite n={2} />.

A server can offer three kinds of things <Cite n={2} />: **tools** (functions that the AI can call), **resources** (data, such as a file or a database schema), and **prompts** (reusable templates). The client first asks for the list (`tools/list`) and then calls a tool (`tools/call`) <Cite n={2} />. Each tool has a name, a description, and an `inputSchema` in JSON Schema <Cite n={2} />. A server can also ask the user for more input or for a confirmation (**elicitation**) <Cite n={2} />.

In Claude Code, you add a server with `claude mcp add`. For a remote server: `claude mcp add --transport http <name> <url>`. For a local one, put the start command after `--` <Cite n={4} />. A server can have the scope local, project, or user, and the project scope is saved in `.mcp.json` at the project root <Cite n={4} />. The `/mcp` command shows the servers and handles OAuth logins <Cite n={4} />. The older SSE transport is deprecated <Cite n={4} />. Apps built on the Claude API can use the MCP connector, which reaches MCP servers from the Messages API with no MCP client of your own <Cite n={6} />.

</Technical>

MCP-তে তিনটা ভূমিকা আছে <Cite n={2} />:

- **Host** হলো AI অ্যাপ, যেমন Claude Code।
- Host প্রতিটা server-এর জন্য একটা করে **client** বানায়। প্রতিটা client তার server-এর সাথে নিজের আলাদা কানেকশন রাখে।
- **Server** হলো একটা প্রোগ্রাম, যা client-কে কনটেক্সট দেয়।

যেমন, Claude Code হলো host। একটা client আপনার মেশিনের একটা Playwright server-এর সাথে কথা বলে। আরেকটা client একটা রিমোট issue tracker server-এর সাথে কথা বলে। তৃতীয় একটা client আপনার মেশিনের একটা টেস্ট ডেটাবেস server-এর সাথে কথা বলে।

মেসেজগুলো JSON-RPC 2.0 ব্যবহার করে <Cite n={2} />। যুক্ত হওয়ার দুটো উপায় (transport) আছে। **stdio** একই মেশিনের দুটো প্রোগ্রামকে যুক্ত করে। **Streamable HTTP** একটা রিমোট server-এর সাথে যুক্ত করে। এটা bearer token, API key আর custom header সাপোর্ট করে। টোকেনের জন্য MCP OAuth সুপারিশ করে <Cite n={2} />।

একটা server তিন ধরনের জিনিস দিতে পারে <Cite n={2} />। **Tools** হলো ফাংশন, যা AI কল করতে পারে। **Resources** হলো ডেটা, যেমন একটা ফাইল বা ডেটাবেস schema। **Prompts** হলো বারবার ব্যবহারযোগ্য টেমপ্লেট। Client প্রথমে তালিকা চায় (`tools/list`), তারপর একটা টুল কল করে (`tools/call`) <Cite n={2} />। প্রতিটা টুলের একটা নাম, একটা বর্ণনা আর JSON Schema-তে একটা `inputSchema` থাকে <Cite n={2} />। একটা server ইউজারের কাছে আরও ইনপুট বা একটা নিশ্চিতকরণও চাইতে পারে। একে বলে **elicitation** <Cite n={2} />।

Claude Code-এ `claude mcp add` দিয়ে একটা server যোগ করেন। রিমোট server-এর জন্য: `claude mcp add --transport http <name> <url>`। লোকাল server-এর জন্য চালু করার কমান্ড `--`-এর পরে দিন <Cite n={4} />। একটা server-এর scope হতে পারে local, project বা user। Project scope প্রজেক্টের রুটে `.mcp.json`-এ সেভ হয় <Cite n={4} />। `/mcp` কমান্ড server-গুলো দেখায় আর OAuth লগইন সামলায় <Cite n={4} />। পুরোনো SSE transport deprecated <Cite n={4} />। Claude API দিয়ে বানানো অ্যাপ MCP connector ব্যবহার করতে পারে। এটা নিজের কোনো MCP client ছাড়াই Messages API থেকে MCP server-এ পৌঁছায় <Cite n={6} />।

## How a tester uses it

<Voices>
<Technical>

**Drive a browser.** Playwright MCP gives the AI browser tools. It works from structured page data, with no vision model <Cite n={5} />. Ask it to open a staging page, fill a form with edge-case values, and report what breaks. See [Playwright](/automate/playwright/) for turning a session into a real test.

**Read the bug tracker and the docs.** A remote server for your issue tracker lets the assistant read a ticket, check the steps against the app, and draft a comment for you to review. Add it with the `--transport http` form <Cite n={4} />.

**Query a test database.** The MCP docs describe a database server with tools that run queries, a resource with the schema, and a prompt with examples <Cite n={2} />. With it, you can ask "which test users have an expired card?" and get the rows without writing SQL first.

**Share the setup with the team.** Use the project scope, so the server list lives in `.mcp.json` in the repo <Cite n={4} />. Every tester then gets the same connectors.

**Test an MCP server that your team builds.** Check `tools/list`, call each tool with valid and invalid input against its `inputSchema`, and check the errors <Cite n={2} />. The MCP Inspector is a tool for this kind of work <Cite n={2} />.

<Callout type="tip" title="Tutorial advice">
This is the tutorial's own advice. Give every connector the smallest access that the task needs: a read-only database user, a test project in the tracker, and a staging URL for the browser. Keep tokens in environment variables, never in `.mcp.json`.
</Callout>

</Technical>

**ব্রাউজার চালানো।** Playwright MCP AI-কে ব্রাউজারের টুল দেয়। এটা পেজের structured data দিয়ে কাজ করে, কোনো vision model ছাড়াই <Cite n={5} />। একটা staging পেজ খুলতে, edge-case মান দিয়ে একটা ফর্ম পূরণ করতে, আর কী ভাঙছে তা জানাতে বলুন।

**Bug tracker আর ডকস পড়া।** আপনার issue tracker-এর একটা রিমোট server থাকলে assistant একটা টিকিট পড়তে পারে। সে অ্যাপের সাথে ধাপগুলো মিলিয়ে দেখতে পারে আর আপনার রিভিউয়ের জন্য একটা কমেন্টের খসড়া করতে পারে। `--transport http` রূপে এটা যোগ করুন <Cite n={4} />।

**টেস্ট ডেটাবেসে কুয়েরি।** MCP ডকস একটা ডেটাবেস server-এর কথা বলে, যাতে কুয়েরি চালানোর টুল, schema-সহ একটা resource আর উদাহরণসহ একটা prompt থাকে <Cite n={2} />। এটা দিয়ে আপনি জিজ্ঞেস করতে পারেন "which test users have an expired card?"। আগে SQL না লিখেই সারিগুলো পাবেন।

**দলের সাথে সেটআপ শেয়ার করা।** Project scope ব্যবহার করুন। তাহলে server-এর তালিকা repo-র `.mcp.json`-এ থাকে <Cite n={4} />। প্রত্যেক টেস্টার একই connector পান।

**আপনার দলের বানানো MCP server টেস্ট করা।** `tools/list` দেখুন। প্রতিটা টুলকে তার `inputSchema` অনুযায়ী ঠিক আর ভুল ইনপুট দিয়ে কল করুন। এররগুলো দেখুন <Cite n={2} />। MCP Inspector এই ধরনের কাজের একটা টুল <Cite n={2} />।

এটা টিউটোরিয়ালের নিজের পরামর্শ। প্রতিটা connector-কে কাজের জন্য সবচেয়ে কম অ্যাক্সেস দিন: একটা read-only ডেটাবেস ইউজার, tracker-এ একটা টেস্ট প্রজেক্ট, আর ব্রাউজারের জন্য একটা staging URL। টোকেন environment variable-এ রাখুন, কখনো `.mcp.json`-এ নয়।

## Common mistakes

<Voices>
<Technical>

- **Adding any server you find.** Check that you trust each server first. A server that fetches outside content can bring a prompt injection risk <Cite n={4} />. A local server that is not safe can run any command with the rights of the client <Cite n={3} />. Fix: install servers from sources you know, and read the start command.
- **Broad access.** The MCP security guide recommends a least-privilege model that starts with a minimal set of scopes <Cite n={3} />. Fix: use test accounts with the smallest rights.
- **Secrets in the shared file.** `.mcp.json` is meant for the repo <Cite n={4} />. Fix: pass keys as environment variables, as the `--env` option of `claude mcp add` shows <Cite n={4} />.
- **Using SSE for a new server.** The SSE transport is deprecated <Cite n={4} />. Fix: use Streamable HTTP for remote servers.
- **Testing your own server only on the happy path.** Fix: also send input that breaks the `inputSchema` <Cite n={2} />, and check that a server never accepts a token that was not issued for it <Cite n={3} />.

</Technical>

- **Secrets in the shared file.** `.mcp.json` is meant for the repo <Cite n={4} />. Fix: pass keys as environment variables, as the `--env` option of `claude mcp add` shows <Cite n={4} />.
- **Using SSE for a new server.** The SSE transport is deprecated <Cite n={4} />. Fix: use Streamable HTTP for remote servers.
- **Testing your own server only on the happy path.** Fix: also send input that breaks the `inputSchema` <Cite n={2} />. Check that a server never accepts a token that was not made for it <Cite n={3} />.

</Layman>
<Bangla>

- **যা পান সেই server যোগ করা।** আগে দেখুন প্রতিটা server-কে আপনি বিশ্বাস করেন কিনা। যে server বাইরের কনটেন্ট আনে, সে prompt injection-এর ঝুঁকি আনতে পারে <Cite n={4} />। একটা অনিরাপদ লোকাল server client-এর অধিকার নিয়ে যেকোনো কমান্ড চালাতে পারে <Cite n={3} />। সমাধান: পরিচিত সোর্স থেকে server ইনস্টল করুন। চালু করার কমান্ডটা পড়ে দেখুন।
- **বেশি অ্যাক্সেস।** MCP-র সিকিউরিটি গাইড least-privilege মডেল সুপারিশ করে, যা সবচেয়ে কম scope দিয়ে শুরু হয় <Cite n={3} />। সমাধান: সবচেয়ে কম অধিকারসহ টেস্ট অ্যাকাউন্ট ব্যবহার করুন।
- **শেয়ার করা ফাইলে secret।** `.mcp.json` repo-তে রাখার জন্য <Cite n={4} />। সমাধান: key-গুলো environment variable হিসেবে দিন, যেমন `claude mcp add`-এর `--env` অপশন দেখায় <Cite n={4} />।
- **নতুন server-এ SSE ব্যবহার।** SSE transport deprecated <Cite n={4} />। সমাধান: রিমোট server-এর জন্য Streamable HTTP ব্যবহার করুন।
- **নিজের server শুধু happy path-এ টেস্ট করা।** সমাধান: `inputSchema` ভাঙে এমন ইনপুটও পাঠান <Cite n={2} />। দেখুন server যেন কখনো তার জন্য দেওয়া হয়নি এমন টোকেন গ্রহণ না করে <Cite n={3} />।

</Bangla>
</Voices>

## How to start

<Voices>
<Technical>

1. Add Playwright MCP to Claude Code with the command in the table above <Cite n={5} />.
2. Run `/mcp` and check that the server is connected <Cite n={4} />.
3. Ask Claude to open your staging site and walk through one flow. Read every tool call that it asks to run.
4. Add one more server for a system that you use every day, with a test account.
5. When the setup works, move it to the project scope so that the team shares it <Cite n={4} />. Then read [MCP](/extend/mcp/) and [Hooks](/extend/hooks/) to add guard rails.
