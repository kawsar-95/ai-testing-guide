# What Is k6?

An open-source load testing tool where you write the test as JavaScript.

<PageMeta />

## What k6 is

<Voices>
<Technical>

**k6** is an open-source tool for performance testing. It is easy for developers to use, and you can extend it <Cite n={1} />. Developers, QA engineers, SDETs, and SREs use it <Cite n={1} />. The k6 project describes it as a modern load-testing tool, and its key design goal is the best developer experience <Cite n={2} />.

Its scripts are JavaScript, and k6 runs them in an embedded JavaScript engine. The project says this gives the performance of Go with the scripting familiarity of JavaScript <Cite n={2} />. The tool is optimized for minimal resource consumption, so it suits high-load tests such as spike, stress, and soak tests <Cite n={1} />.

The license is AGPL-3.0 <Cite n={2} />. The docs call it Grafana k6 <Cite n={1} />.

A test is a short file. This script sends one request to the QuickPizza demo site:

```js
import http from 'k6/http';

export default function () {
  http.get('https://quickpizza.grafana.com');
}
```

The next page installs k6 and runs a full script.

</Technical>

## JavaScript, but not Node.js

<Voices>
<Technical>

The owner's notes say that people who know JavaScript or Node.js learn k6 easily. The first part is right. The second part needs a correction. k6 is not Node.js and it is not a browser <Cite n={4} />.

This has 3 effects <Cite n={4} />:

- Packages that need Node.js APIs, such as the `os` and `fs` modules, do not work in k6.
- k6 resolves modules like a browser. You write the full file name, for example `./helpers.js`. It does not use Node.js module resolution.
- To use npm packages, you build your script with a bundler first.

Your script imports k6 modules, such as `k6/http`. These modules come with k6 <Cite n={4} />.

</Technical>

## What k6 can test and how you extend it

<Voices>
<Technical>

Out of the box, k6 supports HTTP/1.1, HTTP/2, WebSockets, and gRPC <Cite n={3} />. By default k6 starts with HTTP/1.1. If the server supports HTTP/2, k6 upgrades the connection by itself <Cite n={3} />.

The k6 browser API runs browser-based performance tests and collects browser metrics <Cite n={1} />.

Extensions add features that the core does not have. k6 has 4 types of extensions: JavaScript, output, secret source, and subcommand <Cite n={8} />. Community extensions add protocols such as SQL, Kafka, ZeroMQ, and Redis. You build a k6 binary with them using the `xk6` tool <Cite n={3} />.

If you do not want to write code, k6 Studio is a desktop app that makes scripts for you <Cite n={2} />.

</Technical>
