# Programming Problem Solving

Test code is full of small problems: count the items in a list, find a duplicate, check an order, clean a string. This page solves four of them in JavaScript, each with a test that proves it. It also shows two traps that catch many people: the default sort and text in Bangla.

## What it is

<Voices>
<Technical>

Problem solving here means turning a small, exact task into code, and then proving that the code works. The proof is a test. The `node:test` module of Node.js creates JavaScript tests <Cite n={8} />. A synchronous test fails if it throws an exception, and passes otherwise <Cite n={8} />.

Most of these problems need only a few tools of the language. A `for...of` loop walks over an array, a `Map`, or a `Set` <Cite n={11} />. A `Map` holds key-value pairs <Cite n={4} />, and a value can occur in a `Set` only once <Cite n={3} />.

The language basics are on [JavaScript for Testers](/sdet/javascript/). This page uses them to solve problems.

## How it works

<Voices>
<Technical>

- **Counting.** A `Map` holds key-value pairs <Cite n={4} />, so it can keep each item as a key and its count as the value. Lower-case the text first with `toLowerCase()`, so that `Test` and `test` count as one word <Cite n={10} />.
- **Duplicates.** A value occurs in a `Set` only once <Cite n={3} />. `firstDuplicate()` below adds each item to a `Set` and returns the first item that is already in it.
- **Sorting.** `sort()` sorts the array in place and returns the same array <Cite n={1} />. By default it converts the elements to strings and compares those <Cite n={1} />. For numbers, pass a compare function, such as `(a, b) => a - b`, which subtracts `b` from `a` <Cite n={1} />. A negative result puts `a` before `b`, and a positive one puts `a` after `b` <Cite n={1} />. `toSorted()` is the copying version: it returns a new, sorted array <Cite n={2} />.
- **Reversing.** `reverse()` reverses an array in place <Cite n={7} />.
- **Text.** `length` returns the number of UTF-16 code units, not the number of characters <Cite n={12} />. `split("")` also splits by UTF-16 code units, not by the characters that a reader sees <Cite n={5} />. `Intl.Segmenter` splits text into graphemes, words, or sentences <Cite n={6} />.

</Technical>
<Layman>

- **Counting.** A `Map` holds pairs of a key and a value <Cite n={4} />, so it can keep each word with its count. Make the text lower-case first, so `Test` and `test` count as the same word <Cite n={10} />.
- **Duplicates.** A `Set` keeps each value once <Cite n={3} />. `firstDuplicate()` below returns the first item that is already in its `Set`.
- **Sorting.** `sort()` changes the array itself <Cite n={1} />. By default it sorts as text, not as numbers <Cite n={1} />. For numbers, give it a compare function, like `(a, b) => a - b` <Cite n={1} />. `toSorted()` gives you a sorted copy and leaves the original alone <Cite n={2} />.
- **Reversing.** `reverse()` turns the array itself around <Cite n={7} />.
- **Text.** `length` counts code units, not the letters you see <Cite n={12} />. `split("")` cuts by code units too <Cite n={5} />. `Intl.Segmenter` cuts text into the pieces a reader sees <Cite n={6} />.

</Layman>
<Bangla>

- **গণনা।** `Map` key-value জোড়া রাখে <Cite n={4} />, তাই এতে প্রতিটা item-কে key আর তার গণনাকে value হিসেবে রাখা যায়। আগে `toLowerCase()` দিয়ে text ছোট হাতের করুন, যাতে `Test` আর `test` একই শব্দ হিসেবে গোনা হয় <Cite n={10} />।
- **Duplicate।** `Set`-এ একটা value একবারই থাকে <Cite n={3} />। নিচের `firstDuplicate()` প্রতিটা item একটা `Set`-এ রাখে, আর যে item আগে থেকেই সেখানে আছে, প্রথম এমন item-টা ফেরত দেয়।
- **Sort।** `sort()` array-টাকেই সাজায় আর একই array ফেরত দেয় <Cite n={1} />। ডিফল্টভাবে এটা element-গুলোকে string বানিয়ে তুলনা করে <Cite n={1} />। Number-এর জন্য `(a, b) => a - b`-এর মতো একটা compare function দিন, যেটা `a` থেকে `b` বিয়োগ করে <Cite n={1} />। ফল negative হলে `a` আগে বসে, positive হলে `a` বসে `b`-এর পরে <Cite n={1} />। `toSorted()` হলো copy করা version: এটা একটা নতুন, সাজানো array দেয় <Cite n={2} />।
- **উল্টানো।** `reverse()` array-টাকেই উল্টে দেয় <Cite n={7} />।
- **Text।** `length` UTF-16 code unit-এর সংখ্যা দেয়, character-এর সংখ্যা নয় <Cite n={12} />। `split("")`-ও UTF-16 code unit ধরে ভাগ করে, পাঠক যে character দেখেন সেই ধরে নয় <Cite n={5} />। `Intl.Segmenter` text-কে grapheme, শব্দ বা বাক্যে ভাগ করে <Cite n={6} />।

## Try it

<Voices>
<Technical>

Save the solutions as `solutions.mjs`:

```js
export function countWords(text) {
  const counts = new Map();
  for (const word of text.toLowerCase().split(' ')) {
    if (word === '') continue;
    counts.set(word, (counts.get(word) ?? 0) + 1);
  }
  return counts;
}

export function firstDuplicate(items) {
  const seen = new Set();
  for (const item of items) {
    if (seen.has(item)) return item;
    seen.add(item);
  }
  return null;
}

export function sortNumbers(numbers) {
  return numbers.toSorted((a, b) => a - b);
}

export function reverseText(text) {
  const segmenter = new Intl.Segmenter('bn', { granularity: 'grapheme' });
  return [...segmenter.segment(text)].map((part) => part.segment).reverse().join('');
}
```

Save the tests next to it as `solutions.test.mjs`:

```js
import test from 'node:test';
import assert from 'node:assert/strict';
import { countWords, firstDuplicate, sortNumbers, reverseText } from './solutions.mjs';

test('counts words without caring about case', () => {
  const counts = countWords('Test the test  TEST plan');
  assert.equal(counts.get('test'), 3);
  assert.equal(counts.get('plan'), 1);
});

test('finds the first duplicate, or null', () => {
  assert.equal(firstDuplicate([3, 1, 4, 1, 5, 3]), 1);
  assert.equal(firstDuplicate([1, 2, 3]), null);
  assert.equal(firstDuplicate([]), null);
});

test('sorts numbers as numbers and keeps the input', () => {
  const input = [10, 9, 1, 100];
  assert.deepEqual(sortNumbers(input), [1, 9, 10, 100]);
  assert.deepEqual(input, [10, 9, 1, 100]);
});

test('reverses Bangla text by what a reader sees', () => {
  assert.equal(reverseText('abc'), 'cba');
  assert.equal(reverseText('কি খবর'), 'রবখ কি');
});
```

Run `node --test` in the folder <Cite n={8} />. It runs files whose names end in `.test.mjs` <Cite n={8} />, and all four tests pass. From `node:assert/strict`, `assert.equal` is strict equality <Cite n={9} />, and `assert.deepEqual` tests deep equality <Cite n={9} />.

Now save the two traps of this page as `traps.mjs`, and run `node traps.mjs`:

```js
console.log([10, 9, 1, 100].sort());
console.log('কি'.length);
console.log('কি'.split('').reverse().join(''));
```

It prints `[ 1, 10, 100, 9 ]`, then `2`, then `িক`: the default sort compared strings, `length` counted 2 code units for one letter that a reader sees, and the reversed text put the vowel sign first.

Then break each solution on purpose, for example sort with `numbers.sort()`, and watch which test fails. A test that never fails proves nothing.

</Technical>

## How a tester uses it

<Voices>
<Technical>

- **Check that a list is sorted.** Read the values from the page or the API, sort a copy with `toSorted()` <Cite n={2} />, and compare the two. Use a compare function for numbers <Cite n={1} />.
- **Find duplicates in a response.** A value occurs in a `Set` only once <Cite n={3} />: if the `Set` of the ids is smaller than the list of ids, an id came back twice.
- **Count what came back.** Count the statuses or types of a long response in a `Map`, which holds key-value pairs <Cite n={4} />, and compare the counts with the ones you expect.
- **Test with Bangla text.** `length` counts code units, not the characters that a reader sees <Cite n={12} />: the traps file printed `2` for `কি`. `Intl.Segmenter` splits text into graphemes <Cite n={6} />. Use it when a limit, a counter, or a cut must follow what the user sees.
- **Test the helpers.** Test helpers are code too: give each helper a small test file. The `node:test` module creates JavaScript tests <Cite n={8} />.

</Technical>

- **Check that a list is sorted.** Read the values, make a sorted copy with `toSorted()` <Cite n={2} />, and compare. Use a compare function for numbers <Cite n={1} />.

- **Count what came back.** Count each status in a `Map`, which holds pairs of a key and a value <Cite n={4} />, and compare the counts with what you expect.
- **Test with Bangla text.** `length` counts code units, not the letters you see <Cite n={12} />: the traps file printed `2` for `কি`. `Intl.Segmenter` cuts text into graphemes <Cite n={6} />. Use it when a limit or a counter must follow what the user sees.
- **Test the helpers.** Helpers are code too: give each one a small test file. `node:test` makes JavaScript tests <Cite n={8} />.

- **Response-এ duplicate খুঁজুন।** `Set`-এ একটা value একবারই থাকে <Cite n={3} />: id-গুলোর `Set` যদি id-এর list-এর চেয়ে ছোট হয়, তাহলে কোনো id দুবার এসেছে।
- **কী এল, তা গুনুন।** লম্বা response-এর status বা type-গুলো একটা `Map`-এ গুনুন, যেটা key-value জোড়া রাখে <Cite n={4} />, তারপর গণনাগুলো প্রত্যাশিত গণনার সাথে মেলান।
- **বাংলা text দিয়ে টেস্ট করুন।** `length` code unit গোনে, পাঠক যে character দেখেন তা নয় <Cite n={12} />: traps file `কি`-এর জন্য `2` দেখিয়েছে। `Intl.Segmenter` text-কে grapheme-এ ভাগ করে <Cite n={6} />। কোনো limit, counter বা কাটাছেঁড়া যখন user যা দেখেন সেই ধরে চলতে হবে, তখন এটা ব্যবহার করুন।
- **Helper-এরও টেস্ট।** টেস্টের helper-ও কোড: প্রতিটা helper-কে একটা ছোট টেস্ট file দিন। `node:test` module JavaScript টেস্ট তৈরি করে <Cite n={8} />।

</Bangla>
</Voices>

## Common mistakes

<Voices>
<Technical>

- **The default sort on numbers.** The default sort compares strings <Cite n={1} />: the traps file printed `[ 1, 10, 100, 9 ]`. Pass a compare function such as `(a, b) => a - b` <Cite n={1} />.
- **Changing the input by accident.** `sort()` and `reverse()` change the array in place <Cite n={1} /> <Cite n={7} />. Use `toSorted()` when the caller still needs the original <Cite n={2} />.
- **Reversing text with `split("")`.** It splits by UTF-16 code units, not by what a reader sees <Cite n={5} />: the traps file turned `কি` into `িক`, with the vowel sign first.
- **Trusting `length` for a character limit.** The value of `length` may not match the number of characters <Cite n={12} />.
- **Testing only the happy path.** Give each problem its edge cases too: an empty input, a single item, and a repeated item. The tests above check an empty list for `firstDuplicate`, and a double space for `countWords`.

</Technical>

## What a tester can check

<Voices>
<Technical>

<Callout type="tip" title="Tutorial advice">

- **Say the problem back.** Can you state the input, the output, and one example in one sentence each before you write code?
- **Examples first.** Are the examples written as tests before the solution, including the empty and the one-item case?
- **The simple way first.** Does a plain loop solve it before you look for a clever method?
- **Inputs left alone.** Does the solution leave its input unchanged, unless that is its job?

## Key words

| Term | Meaning |
|---|---|
| `Map` | An object that holds key-value pairs. |
| `Set` | A collection in which each value occurs once; good for duplicates. |
| `sort()` | Sorts in place; by default it compares the elements as strings. |
| Compare function | `(a, b) => a - b`: negative puts `a` first, positive puts `b` first. |
| `toSorted()` | Returns a sorted copy and leaves the original unchanged. |
| `for...of` | A loop over the items of an array, a `Map`, or a `Set`. |
| Code unit | A UTF-16 code unit of a JavaScript string; `length` counts these. |
| Grapheme | A unit that `Intl.Segmenter` can split text into, next to words and sentences. |
| `Intl.Segmenter` | Splits text into graphemes, words, or sentences. |
| `node:test` | The test runner of Node.js; run it with `node --test`. |
| Edge case | An unusual input that a solution must also handle, such as an empty input, a single item, or a repeated item. |
